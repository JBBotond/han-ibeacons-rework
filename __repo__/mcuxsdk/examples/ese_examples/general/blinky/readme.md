# Blinky

## Overview
Blinky application to verify IDE setup and toolchain installation.
It uses one of the available LEDs on the board to blink at a fixed interval.

## Supported Boards
- [FRDM-MCXA153](../../../_boards/frdmmcxa153/ese_examples/general/blinky/example_board_readme.md)
- [FRDM-MCXN947](../../../_boards/frdmmcxn947/ese_examples/general/blinky/example_board_readme.md)

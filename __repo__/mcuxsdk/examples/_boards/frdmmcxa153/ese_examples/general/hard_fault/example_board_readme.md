# General - Hard fault

## Overview
Hard fault example project

## Details
Do you want to know more details about this example? Check the [details](https://ese.han.nl/~harends/frdm-mcxa153-site/index.html).

## Hardware requirements
- FRDM-MCXA153 board
- Type-C USB cable

## Board settings
- Default

## Preparation
- Connect the type-C USB cable between the host PC and the MCU-Link port (J15) on the target board.
- Build the application.
- Run or debug the application.

## Result
- The green LED should be blinking, but it is not due to hard fault errors.
- Solve these mistakes by using the debugger.

Overview
========
Mastermind game and solver for the oled_sdcard_buzzer shield on the FRDM-MCXA153 board.

Hardware requirements
=====================
- FRDM-MCXA153 board
- Type-C USB cable
- OLED_SDCARD_BUZZER shield

Board settings
==============
- Default

Preparation
===========
- Connect the OLED_SDCARD_BUZZER shield to the FRDM-MCXA153 board using the MikroBUS connector.
- Connect a type-C USB cable between the host PC and the MCU-Link port (J15) on the target board.
- Build the application.
- Run the application.

Result
======
- The OLED shows two options:
    1. Play a game of Mastermind
    2. Solve a Mastermind game
- Follow the instructions on the OLED to play or solve a game of Mastermind.
